# Porträts für das Kernteam

Die Startseite sucht hier selbst nach Bildern. Liegt eine Datei unter
dem erwarteten Namen, erscheint sie; fehlt sie, bleibt die
Dither-Fläche stehen. Kein Eingriff in den Code nötig — ablegen,
`npm run build`, fertig.

| `julius-heinisch.jpg`  | fehlt            |
| `shakil-rifaat.jpg`    | fehlt            |

**Format:** quadratisch, mindestens 640 × 640 px, JPG oder WebP. Die
Seite rechnet selbst herunter und stellt auf Graustufen um — also
ruhig das farbige Original ablegen.

## Damit die fünf als Serie wirken

Das vorhandene Bild von Daniel Kontelis gibt den Ton vor. Wer die
übrigen erzeugen lässt, sollte dieselben vier Dinge vorgeben, sonst
sieht die Reihe aus wie fünf Bilder aus fünf Quellen:

```
Hintergrund   schlicht, hellgrau, ohne Struktur
Licht         weich von vorne, keine harten Schatten
Kleidung      schlichtes dunkles Oberteil, kein Muster
Ausschnitt    Kopf und Schultern, Blick in die Kamera
```

Ein Prompt, der das zusammenfasst:

> Fotorealistisches Porträt, quadratisch, Kopf und Schultern, Blick
> direkt in die Kamera, freundlicher Ausdruck, schlichter hellgrauer
> Studiohintergrund ohne Struktur, weiches Frontlicht, schlichtes
> dunkles T-Shirt oder Hemd ohne Muster, natürliche Hauttöne, kein
> Filter, kein Text, kein Logo.

## Ein Hinweis, bevor die Bilder entstehen

Ein erzeugtes Gesicht unter einem echten Namen zeigt eine Person, die
es so nicht gibt. Bei Daniel Kontelis ist das unkritisch — es ist sein
eigenes Bild, von ihm ausgewählt. Bei den Kolleginnen und Kollegen
wäre es ein fremdes Gesicht mit ihrem Namen darunter.

Das ist keine Rechtsfrage, sondern eine der Erwartung: Wer auf einer
Agenturseite ein Porträt sieht, geht davon aus, dass ihm diese Person
gegenübersitzt, wenn er anruft. Zwei Wege, die das auflösen:

1. **Echte Fotos.** Ein Nachmittag mit einer Kamera, und die Frage
   stellt sich nicht mehr.
2. **Bei den Dither-Flächen bleiben.** Sie behaupten kein Gesicht und
   passen zur Bildsprache der Seite.

Wer sich trotzdem für erzeugte Porträts entscheidet, sollte es mit dem
Einverständnis der Abgebildeten tun — es ist ihr Name, der darunter
steht.
